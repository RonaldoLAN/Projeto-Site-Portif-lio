# Portifólio

Este é um projeto simples de portfólio, desenvolvido com o objetivo de praticar e consolidar conhecimentos em **HTML** e **CSS**.

## 🎯 Objetivo

Um projeto de estudo focado em fixar conceitos fundamentais de estruturação de páginas web e estilização, sem uso de frameworks ou bibliotecas externas (além de fontes do Google Fonts).

## 🛠️ Tecnologias utilizadas

- **HTML5** – estruturação do conteúdo
- **CSS3** – estilização e responsividade (Flexbox, media queries)
- **Google Fonts** – fonte Roboto

## 📁 Estrutura do projeto

```
├── index.html      # Estrutura da página
├── style.css       # Estilos da página
└── images/         # Imagens utilizadas no projeto
```

## 📄 Seções da página

- **Home** – seção de destaque com chamada para ação
- **Sobre** – breve apresentação pessoal
- **Projetos** – galeria com projetos em destaque
- **Footer** – informações de rodapé

## 📱 Responsividade

O projeto conta com media queries para adaptação em telas menores (até 1050px), ajustando fontes, imagens e layout das seções.

## 🚀 Como executar

Basta abrir o arquivo `index.html` em qualquer navegador, ou usar uma extensão como o *Live Server* no VS Code.

## 📌 Observação

Este projeto tem fins **exclusivamente didáticos**, sendo indicado para quem está aprendendo os fundamentos de HTML e CSS.
